# Measurement rules

1. **One variable at a time.** Same tablet or PC, same OS version, same router, same printer model, same
   30-item menu, same tester for every system compared.
2. **Real plan, default settings.** Test what you would actually buy. Disable nothing the vendor turns on by default.
3. **Clock source.** Use a screen recording with a visible clock, or a stopwatch app filmed together with the screen.
   Do not time with your own reaction on a phone.
4. **Repeat.** Run each scenario at least 3 times. Report the median and the min–max spread.
5. **Warm up.** Do one throwaway sale before timing, so first-load caching is not blamed on the system.
6. **No estimates.** A field you did not measure stays `null`.
7. **Evidence.** Every number must be traceable to a recording, photo or log in `evidence/`.
8. **Conflicts of interest.** State whether you are the vendor, an owner/employee, a customer, or independent.
9. **Versions.** Record the app/web version and date. Systems change; results are dated.
10. **Do not test on a live restaurant's real data.** Use a trial or demo account.
